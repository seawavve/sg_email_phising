1. 🥇 **Logistic Regression (기본)** - 98.24%
2. 🥈 **BERT** - 87.00%
3. 🥉 **Gemini** - 48.00%

### 주요 인사이트

#### ✅ Logistic Regression의 우수성
- **가장 높은 정확도 (98.24%)**
- **가장 빠른 학습 시간 (10초)**
