# 파이썬 기말 프로젝트: 피싱 이메일 탐지 모델 분석 및 성능 개선

## 데이터 수집 및 EDA
Kaggle에서 피싱 이메일 데이터를 수집한 뒤, 다양한 시각화 기법을 활용하여 데이터의 구조와 특성을 탐색했다.

## 모델 실험
데이터 분석한 내용을 토대로 feature 활용방안을 생각해서 모델을 선정하고 실험후 개선함
각 모델을 Accuracy, Precision, Recall, F1-score 등의 지표를 이용해 모델 성능을 정량적으로 분석하고 시각화했다.

- BERT 모델 활용
Classification Task에 자연어 데이터를 사용하니, 인코더 형식의 버트 모델이 적절하다 판단.
모델 학습 자원이 부족하여 huggingface에서 모델 다운로드 후 라벨을 뭉쳐서 활용

- Gemini sLLM 모델 활용
모델이 어떤 로직으로 레이블을 판단하는지도 알 수 있도록하기 위해서 선정하여 실험함.
huggingface에서 모델 다운로드 후 Few Shot 기법 + CoT 기법을 활용함

- XAI + Logistic Regression 모델 활용
TF-IDF + Logistic Regression 모델을 활용하여 더욱 inference 시간을 빠르게 개선하고, 
모델의 의사결정 과정을 더 잘 이해하기 위해 XAI(eXplainable AI) 기법을 적용하였다. 
로지스틱 회귀 모델이 제공하는 회귀 계수(coefficient) 를 활용하여, 특정 단어나 피처가 피싱(1) 또는 정상(0) 클래스로 분류되도록 얼마나 강하게 기여하는지를 분석후 시각화함

## Future Work
본 프로젝트는 피싱 이메일 탐지 모델의 정량·정성 평가를 모두 수행하며 고도화를 시도하였지만, 여전히 성능을 한 단계 더 끌어올리기 위해 추가적으로 고려해야 할 방향들이 존재한다. 향후에는 다음과 같은 개선 전략을 중심으로 연구를 확장할 계획이다.

1) 데이터 추가 수집

현재 데이터셋은 공개된 Kaggle 셋을 기반으로 하여 이메일 도메인이 비교적 제한적이다.
아래와 같은풍부한 데이터를 수집하여 이 기반 위에서 모델은 더 견고한 일반화 능력을 갖추게 될 것이다.

실제 기업 환경에서 수집한 내부 이메일 패턴
피싱 유형의 최신 트렌드를 반영한 추가 데이터
다양한 언어·국가·서비스 환경에서 나타나는 공격 패턴

2) 다양한 모델 아키텍처 및 하이브리드 접근 실험

본 프로젝트에서는 전통적 ML 모델, BERT 계열 모델, 그리고 경량 오픈 LLM까지 폭넓게 실험을 진행했지만, 아직 탐색 가능한 모델 공간은 매우 넓다.
향후에는 더 좋은 자원으로 RNN/Attention 기반의 경량 모델, LLM모델 등을 실험하여 현재 모델의 한계를 보완하고, 실제 서비스 환경을 고려한 최적의 모델 아키텍처를 탐색할 계획이다.

느낀점

이번 프로젝트를 통해 수업에서 배운 다양한 기법들을 실제 데이터 분석 흐름에 자연스럽게 적용해볼 수 있었다. 특히 생성형 AI와 여러 AI 도구들을 적극 활용하면서, 짧은 시간 안에 모델을 설계하고 디벨롭하는 과정을 경험할 수 있었던 점이 매우 인상적이었다.
또한, 모델 개선 사이클을 여러 번 반복하며 데이터 전처리, 피처 분석, 고도화 실험까지 전 과정을 직접 수행해보면서 모델의 발전점을 발견해 나가는 과정이 즐거웠다. 

아쉬운점

가장 아쉬웠던 부분은 GPU 리소스 제한으로 인해 BERT fine-tuning이나 LLM fine-tuning과 같은 고성능 실험을 직접 수행하지 못했다는 점이다. 또한 모델별로 test_num 값이나 epoch 수를 다양하게 설정하여 더 정밀한 파라미터 비교 실험을 해보지 못한 것도 아쉬움으로 남았다.

하지만 이러한 제한적인 환경 속에서도, 주어진 Task를 해결하기 위해 다양한 모델 구조를 탐색하고 경량 모델을 최적화하며 최대 성능을 끌어내려는 시도는 충분히 의미 있었다고 생각한다. 오히려 자원이 부족한 상황에서 가장 효율적인 접근을 찾는 과정 자체가 큰 배움이 되었고, 실제 업무 환경에서도 중요한 문제 해결 능력으로 이어질 것이라 느꼈다.

## 시행착오

LLMCRIT 논문을 읽고 자동 정성평가 체계를 구축한다음 개선점 제안까지 자동화를 시도함.

LLMCRIT 논문 읽기 :모델의 발전을 위해 Moonlight를 통해 LLMCRIT 논문을 읽고 자동평가 프레임워크을 학습하였다.
정성 평가 지표 생성 : LLMCRIT 논문의 일부 개념을 적용하여 모델 출력에 대한 정성 평가 지표를 추출함.
해당 논문은 LLM이 스스로 평가 기준(criteria)을 생성하고, 그 기준에 따라 자연어 피드백(NL Feedback)을 자동으로 만들어내는 프레임워크를 제안한다. 이 LLMCRIT: Teaching Large Language Models to Use Criteria 논문에서 착안하여 자연어 모델 평가 및 개선점 방안을 추출하고자 한다.

이 연구의 핵심 개념을 바탕으로, 본 프로젝트에서는 다음과 같은 방향성을 설정하였다.

LLM이 직접 정성적 평가 기준을 생성하도록 유도하여, 사람이 아닌 모델이 스스로 평가 지표를 정의하게 함.
생성된 평가 기준에 대해 LLM as a Judge 방식을 활용하여 모델의 출력을 정성적으로 평가함.
정량적 지표(Accuracy, F1-score 등)뿐만 아니라, 정성적 기준을 활용한 다각적 평가 체계를 구축함으로써 모델의 품질을 더 깊이 있게 분석하고 개선할 수 있도록 함.
